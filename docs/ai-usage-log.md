# AI 利用ログ

## 日付

2026-11-06

## 場面

子ども向けの見た目に変える作業で、デモとイラストの SVG を参考にした

## 使った AI

ChatGPT（デモとイラストはチームメンバーが ChatGPT で作成したものを参考・利用した）

## なぜその場面か

子どもに伝わる見た目とイラストの案を、短い時間で確かめるため

## AI の答えをどう確かめたか

色はコントラストを計算し、基準に届かない色は使わなかった。イラストは実際の画面で、伝わるかを確かめた。HTML とスクリプトは使っていない

## 日付

2026-11-08

## 場面

新しい画面のデザインの参考と、キャラクターの画像（起動、ようこそ、案内、こどもの区切り、終了、つらさの顔）

## 使った AI

ChatGPT と Codex（チームメンバーが作成したものを参考・利用した）。キャラクターの元の画像（PNG）には、ChatGPT と OpenAI で作成した記録（C2PA）が埋め込まれていた。アプリに入れた `public/mascot/` の画像は、表示の大きさに縮めたときにこの記録が外れている

## なぜその場面か

子どもが直感的にわかる見た目とキャラクターを、短い時間で用意するため

## AI の答えをどう確かめたか

参照の画面と API はそのまま使わず、見た目と流れの根拠としてだけ使った（参照の API は Gemini を呼ばず、送るデータの形も今の API と違ったため）。色は明るさの比を計算し、白い文字が読みにくい青は濃くした。画像は暗い背景と明るい背景に並べて、切り出しのごみや隣の顔のはしが残っていないかを確かめた

## 日付

2026-11-05〜2026-11-08

## 場面

アプリのコードの作成、不具合の修正、Gemini への指示文の調整、説明書の作成

## 使った AI

Claude Code（モデルは Claude Fable 5.1 と Claude Opus 5.5）。main ブランチの ed26f34 の時点で、全33コミットのうち30コミットに Co-Authored-By がある（Fable 5.1 が13件、Opus 5.5 が17件）

## なぜその場面か

チームに開発経験がほとんどなかったため、コードを書く・直す・確かめるといった技術的な作業はAIに任せ、人はどの機能を作るか、何を守るかの判断と、結果の確認に時間を使った。

## AI の答えをどう確かめたか

編集のたびに型チェックと lint を通した。画面は実際に動かして確かめ、Gemini の結果は架空のデータで試した。コミットとプッシュはチームメンバーの指示があるときだけ行った

## 運営への確認

開発での AI コーディング支援ツールの利用と、コミットの Co-Authored-By・貢献者欄の表示について運営に確認し、問題ないと回答があった
